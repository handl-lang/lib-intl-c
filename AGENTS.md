# lib-intl-c

`intl_c` — Handl Intl backend over ICU4C. The `icu` (libicui18n) and
`icu-uc` (libicuuc) FFI bindings are codegen-generated and emitted
under `handl-packages/generated/` (gitignored).

## Layout

| path | role |
| --- | --- |
| `src/index.hnl` | the `intl_c` implementation |
| `src/conformance.test.hnl`, `src/intl-c.test.hnl` | tests |
| `src/conformance/` | conformance harness — `generate.mjs` + `cases/*.json` (locale, plural, collator, number/date format, segment, …) |
| `specs/icu.sdkgen.yaml`, `specs/icu-uc.sdkgen.yaml` | committed sdkgen inputs |
| `handl-packages/generated/` | gitignored bindings — regenerated by the gate |
| `pkg.hnl`, `scripts/hnl-gate.sh` | manifest + gate (regen → typecheck/lint/test) |
| `workflows/gate.yaml` | CI — shared `handl-gates` campaign |

## Contract

- Implements the `lib-intl` surface over ICU4C via `ffi.call`; the
  conformance cases are the parity oracle — keep them in sync with
  `generate.mjs`.
- Never commit `handl-packages/generated/` — edit `specs/` and re-emit.

## Verification

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```
