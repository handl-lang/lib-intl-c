# lib-intl-c

`intl_c` — Handl Intl backend over ICU4C. The `icu` (libicui18n) and
`icu-uc` (libicuuc) FFI bindings are codegen-generated and emitted under
`handl-packages/generated/` (a gitignored build artifact).

## Layout

```text
src/        the .hnl sources (intl_c impl + conformance tests)
specs/      committed sdkgen inputs (icu.sdkgen.yaml, icu-uc.sdkgen.yaml)
handl-packages/generated/   build artifact — regenerated by the gate
pkg.hnl     package manifest — modules, deps, description, license
```

## Regenerate

```bash
# one invocation per bound ICU header — see ICU_HEADERS / ICU_UC_HEADERS
# in scripts/hnl-gate.sh
hnl codegen c /usr/include/unicode/ucol.h \
  --output handl-packages/generated/icu \
  --config specs/icu.sdkgen.yaml
```

(needs libclang — set `LIBCLANG_PATH` if the loader cannot find it, and the
ICU dev headers under `/usr/include/unicode/`)

## Gate

```bash
HNL=../host-cli/target/debug/hnl scripts/hnl-gate.sh
```

The gate regenerates `handl-packages/generated/` from `specs/` first, then
typechecks/lints/tests whatever `.hnl` sources exist.
